Configuração do servidor

Modo de manutenção

Quando activo, todas as páginas públicas exibem a mensagem “Em breve estaremos disponíveis — estamos com problemas de conexão.” O painel continua acessível.

Estado actual: inactivo

Ambiente

Servidor aplicacional Uvicorn/ASGI, preparado para publicação atrás do IIS do Windows 11 com ARR + URL Rewrite (proxy reverso para http://127.0.0.1:8080, incluindo WebSockets).

Base de dados: SQLite com WAL e consultas parametrizadas · Sessões assinadas · Cabeçalhos CSP/HSTS activos.

Credenciais

A palavra-passe é guardada apenas como hash PBKDF2-HMAC-SHA256 (260 000 iterações + salt aleatório). Nunca é armazenada em texto simples.

Para alterar defina as variáveis de ambiente ARCH_ADMIN_USER e ARCH_ADMIN_PASS e apague data/archconstroi.db.
